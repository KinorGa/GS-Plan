# 反应伤害公式与实现约定

这份文档只记录当前计算器实际采用的公式和边界，避免 UI、伤害轴、合并表达式和
圣遗物优化器各自解释一套规则。

## 通用直伤

直伤先按倍率属性计算基础伤害，再乘各个乘区：

```text
基础伤害 = 总属性 x 天赋倍率 + 附加伤害
最终伤害 = 基础伤害
         x (1 + 增伤百分比 / 100)
         x 暴击区
         x 防御区
         x 抗性区
         x 增幅反应区
```

攻击力、生命值、防御力的总属性均为：

```text
总属性 = 基础值 x (1 + 百分比 / 100) + 固定值
```

期望暴击区是 `1 + min(暴击率, 100%) x 暴击伤害`；必定暴击是
`1 + 暴击伤害`，不暴击是 `1`。

防御区为：

```text
防御区 = (100 + 攻击方等级)
       / [(100 + 攻击方等级)
          + (100 + 敌人等级) x (1 - 减防) x (1 - 无视防御)]
```

抗性区在抗性大于等于 0 时是 `1 - 抗性`，抗性小于 0 时是
`1 - 抗性 / 2`。

## 增幅反应

蒸发和融化是有方向的增幅反应：

```text
增幅倍率 = 基础倍率 x (1 + 2.78 x EM / (EM + 1400) + 反应伤害提升 / 100)
```

`基础倍率` 为 1.5 或 2.0，取决于触发元素。元素精通加成和“反应伤害提升”
在同一个括号内相加，不是相乘。

实现位置：`src/lib/damage.js` 的 `computeDamage`，代码中标记为
`REF: docs/REACTIONS.md#amplifying`。

## 剧变反应

超载、超导、扩散、感电、燃烧和绽放的伤害是**额外一段伤害**，不是对触发命中的
增幅。它不吃暴击、增伤和天赋倍率，**防御区固定为 1**；只读取等级、反应系数、
元素精通、反应伤害提升和对应抗性。

```text
剧变基础 = 等级基数(攻击方等级) x 反应系数
剧变伤害 = 剧变基础
         x (1 + 16 x EM / (EM + 2000) + 反应伤害提升 / 100)
         x 抗性区
```

因此直伤部分仍然正常经过防御区，而附加的剧变部分不经过防御区。两者相加后才是
该条目在所选暴击模式下的单段伤害。

### 反应系数

| 反应 | 系数 | 反应伤害元素 |
| :-- | --: | :-- |
| 超载 Overloaded | 2.0 | 火 |
| 超导 Superconduct | 0.5 | 冰 |
| 扩散 Swirl | 0.6 | 被扩散元素 |
| 感电 Electro-Charged | 1.2 | 雷 |
| 燃烧 Burning | 0.25 | 火 |
| 绽放 Bloom | 2.0 | 草 |

超绽放和烈绽放的系数均为 3.0，但当前界面尚未提供这两个独立选项，因此没有进入
主计算表。扩散目前按火扩散结算；如果以后要支持其他扩散元素，应把扩散拆成
独立的元素变体，而不是继续猜一个抗性。

冻结、原激化和结晶不产生直接反应伤害：冻结是控制，原激化本身不造成伤害，
结晶生成护盾。它们目前只作为反应类型展示。

### 等级基数

等级基数取自 gcsim 的公开实现：

- <https://github.com/genshinsim/gcsim/blob/main/pkg/core/combat/reaction.dm.go>
- `src/lib/damage.js` 中的 `REACTION_LEVEL_BASE` 保存当前角色等级上限内的 1–90 级表。

实现位置：

- `src/lib/damage.js`：单条目公式与等级表。
- `src/lib/merged-expression.js`：把额外反应伤害写成
  `常数 + 权重 x 16(E+B)/(E+B+2000)`，供优化器使用。
- `native/optimize/main.cpp`：通过 `rx` 记录读取同一组常数和权重。
- `src/DamageCard.jsx`：反应表、系数和 UI 提示。

代码中的 `REF: docs/REACTIONS.md#transformative` 指向本节。

## 激化反应

原激化本身没有直接伤害；超激化和蔓激化把一段伤害加到触发命中上：

```text
激化附加 = 等级基数 x 激化系数
         x (1 + 5 x EM / (EM + 1200) + 反应伤害提升 / 100)
```

激化附加作为基础伤害的一部分，继续经过增伤、暴击、防御和抗性区。当前主界面
还没有超激化/蔓激化选项，因此这条公式只作为后续实现依据，不参与现有计算。

## 多段与触发次数

当前模型把条目上的 `hits` 视为触发次数：直伤和剧变附加都乘以同一个
`hits`。如果一次技能的多段命中并不逐段触发反应，应该拆成独立条目，而不是用
一个 `hits` 强行平均。
