# Artifact substat optimiser

A dependency-free C++17 program that searches substat allocations for ONE
character, and prints the outcomes as CSV.

## Build

From this folder, either:

```bat
build.bat          :: MSVC, in an x64 Native Tools Command Prompt
```

or, with any C++17 compiler on `PATH`:

```bat
g++ -O2 -std=c++17 -Wall -Wextra -o optimize.exe main.cpp
```

`optimize.exe` is a build output and is **not** committed. `/api/optimize`
answers `501` with the command to run when it is missing, so a fresh checkout
reports "not built" instead of failing obscurely.

## Run

```bat
optimize.exe problem.txt [--threads N]
```

The problem file is generated by `src/lib/artifact-optimize.js`; the format is
documented at the top of `main.cpp`. Nothing in here knows about Genshin -- it
reads a panel, per-piece substat rules (which lines a piece may or must carry),
two coefficient vectors (never-crit and always-crit), and returns rows.

Output goes to stdout as CSV (one row per distinct ATK / CRIT RATE / CRIT DMG
outcome, sorted by expected damage, with the current build last and flagged
`is_current=1`); the count of distinct outcomes goes to stderr.

## Why it is not in the page

The search is over how each of the five pieces spends its rolls: four distinct
lines to a piece, at least one roll on each, a per-line cap. A realistic build is
tens of thousands of distinct outcomes; letting every substat be optional on
every piece is hundreds of millions. That is a tight numeric loop, and the one
place the app needs compiled code.
